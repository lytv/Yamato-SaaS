## 🏗️ System Overview

### Business Model
The system follows a **Calculation Batch Approach** where each batch represents a formal salary calculation cycle (monthly, quarterly, etc.).

### Core Components
```mermaid

    G[Batch Templates<br/>Standardization] --> A
```

## 💼 Business Requirements

### Calculation Formula
```typescript
// Core Business Logic
Employee Salary = Σ(Factory Price × Actual Quantity)
Outsource Amount = Σ(Calculated Price × Received)
Total Salary = Employee Salary + Outsource Amount
```

### Data Sources
| Source Table | Field | Usage |
|--------------|-------|--------|
| productionStepDetailSchema | factoryPrice | Employee salary unit price |
| productionStepDetailSchema | calculatedPrice | Outsource unit price |
| employeeSalaryEntrySchema | actualQuantity | Employee work quantity |
| outsourceOrderReceiptSchema | received | Outsource received quantity |

### Business Rules
1. **Default Periods**: Apply to all users unless overridden
2. **Custom Periods**: Support individual user adjustments
3. **Validation**: Require complete data for calculation
4. **Audit Trail**: Track all changes and calculations
5. **Approval Workflow**: Review before finalization
6. **Multi-tenancy**: Respect ownerId isolation

### Use Cases
#### 1. Monthly Payroll Processing
```
HR Manager creates batch "December 2024 Salary"
├── Set period: 2024-12-01 to 2024-12-31
├── Auto-populate all active users
├── Adjust custom periods for special cases
├── Trigger calculation with real-time monitoring
├── Review results and validation errors
└── Finalize and export payroll reports
```

#### 2. Ad-hoc Bonus Calculation
```
Manager needs quarterly bonus calculation
├── Create batch "Q4 2024 Bonus"
├── Select specific high-performing users
├── Set custom periods based on performance
├── Calculate and review for decision making
└── Use results without finalizing
```

#### 3. Audit and Compliance
```
Auditor requests historical verification
├── Query audit log for specific period
├── Trace calculation details to source data
├── Verify formula accuracy and completeness
└── Generate compliance reports
```

## 🗄️ Database Design

### Core Tables

#### calculationBatches
```sql
CREATE TABLE calculation_batches (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  owner_id TEXT NOT NULL,
  name TEXT NOT NULL,
  description TEXT,
  
  -- Period Configuration
  default_start_date TIMESTAMPTZ NOT NULL,
  default_end_date TIMESTAMPTZ NOT NULL,
  
  -- Status Management
  status TEXT NOT NULL DEFAULT 'draft',
    -- Enum: 'draft', 'calculating', 'calculated', 'finalized', 'cancelled'
  
  -- Tracking
  created_by UUID NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  calculated_at TIMESTAMPTZ,
  finalized_at TIMESTAMPTZ,
  finalized_by UUID,
  
  -- Aggregated Data
  total_users INTEGER DEFAULT 0,
  total_employee_salary DECIMAL(15,2) DEFAULT 0,
  total_outsource_amount DECIMAL(15,2) DEFAULT 0,
  grand_total DECIMAL(15,2) DEFAULT 0,
  
  -- Configuration
  auto_calculate_on_create BOOLEAN DEFAULT false,
  allow_user_period_override BOOLEAN DEFAULT true,
  
  -- Enhanced Features
  incremental_mode BOOLEAN DEFAULT false,
  last_full_calculation TIMESTAMPTZ,
  affected_users_count INTEGER DEFAULT 0,
  
  -- Metadata
  notes TEXT,
  metadata JSONB
);
```

#### userCalculationPeriods
```sql
CREATE TABLE user_calculation_periods (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  batch_id UUID NOT NULL REFERENCES calculation_batches(id) ON DELETE CASCADE,
  user_id UUID NOT NULL,
  
  -- Custom Period Override
  custom_start_date TIMESTAMPTZ,
  custom_end_date TIMESTAMPTZ,
  is_custom_period BOOLEAN NOT NULL DEFAULT false,
  exclude_from_calculation BOOLEAN NOT NULL DEFAULT false,
  
  -- Status Tracking
  status TEXT NOT NULL DEFAULT 'pending',
    -- Enum: 'pending', 'calculating', 'calculated', 'excluded', 'error'
  
  -- Enhanced Progress Tracking
  calculation_progress INTEGER DEFAULT 0, -- 0-100%
  last_error_message TEXT,
  retry_count INTEGER DEFAULT 0,
  estimated_completion_time TIMESTAMPTZ,
  
  -- Documentation
  notes TEXT,
  reason_for_custom_period TEXT,
  
  -- Tracking
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  created_by UUID NOT NULL,
  last_calculated_at TIMESTAMPTZ,
  calculation_error TEXT,
  
  UNIQUE(batch_id, user_id)
);
```

#### calculationResults
```sql
CREATE TABLE calculation_results (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  batch_id UUID NOT NULL REFERENCES calculation_batches(id) ON DELETE CASCADE,
  user_id UUID NOT NULL,
  
  -- Calculation Results
  employee_salary_total DECIMAL(15,2) NOT NULL DEFAULT 0,
  outsource_total DECIMAL(15,2) NOT NULL DEFAULT 0,
  grand_total DECIMAL(15,2) NOT NULL DEFAULT 0,
  
  -- Actual Period Used
  actual_start_date TIMESTAMPTZ NOT NULL,
  actual_end_date TIMESTAMPTZ NOT NULL,
  
  -- Statistics
  total_production_steps INTEGER DEFAULT 0,
  total_employee_entries INTEGER DEFAULT 0,
  total_outsource_entries INTEGER DEFAULT 0,
  
  -- Metadata
  calculated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  calculation_duration_ms INTEGER,
  
  -- Validation
  has_validation_errors BOOLEAN DEFAULT false,
  validation_errors JSONB,
  
  -- Source Data Versioning
  source_data_hash TEXT,
  source_data_version TEXT,
  data_change_detection_enabled BOOLEAN DEFAULT true,
  
  -- Notes
  notes TEXT,
  
  UNIQUE(batch_id, user_id)
);
```

#### calculationDetails
```sql
CREATE TABLE calculation_details (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

  -- Employee Salary Details
  employee_salary_quantity DECIMAL(15,4) DEFAULT 0,
  employee_salary_unit_price DECIMAL(15,4) DEFAULT 0,
  employee_salary_amount DECIMAL(15,2) DEFAULT 0,
  
  -- Outsource Details
  outsource_quantity DECIMAL(15,4) DEFAULT 0,
  outsource_unit_price DECIMAL(15,4) DEFAULT 0,
  outsource_amount DECIMAL(15,2) DEFAULT 0,
  
  -- Cached Information
  step_name TEXT,
  step_description TEXT,
  
  -- Source Tracking
  source_employee_entry_ids JSONB,
  source_outsource_receipt_ids JSONB,
  
  -- Performance Optimization
  data_volume_processed INTEGER,
  calculation_complexity_score INTEGER,
  optimization_suggestions JSONB,
  
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

#### calculationNotifications
```sql
CREATE TABLE calculation_notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  batch_id UUID REFERENCES calculation_batches(id) ON DELETE CASCADE,
  user_id UUID,
  
  -- Notification Details
  notification_type TEXT NOT NULL,
    -- Enum: 'email', 'sms', 'in_app', 'system'

    -- Enum: 'low', 'medium', 'high', 'critical'
  
  -- Content
  subject TEXT,
  message TEXT NOT NULL,
  metadata JSONB,
  
  -- Status Tracking
  status TEXT NOT NULL DEFAULT 'pending',
    -- Enum: 'pending', 'sent', 'delivered', 'failed', 'read'
  
  -- Timing
  scheduled_at TIMESTAMPTZ,
  sent_at TIMESTAMPTZ,
  delivered_at TIMESTAMPTZ,
  read_at TIMESTAMPTZ,
  
  -- Tracking
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  -- Failure Handling

  retry_count INTEGER DEFAULT 0,
```


### Relationships
```sql
-- Foreign Key Relationships
ALTER TABLE user_calculation_periods 
  ADD CONSTRAINT fk_user_periods_batch 
  FOREIGN KEY (batch_id) REFERENCES calculation_batches(id);

ALTER TABLE calculation_results 
  ADD CONSTRAINT fk_results_batch 
  FOREIGN KEY (batch_id) REFERENCES calculation_batches(id);

ALTER TABLE calculation_details 
  ADD CONSTRAINT fk_details_result 
  FOREIGN KEY (result_id) REFERENCES calculation_results(id);

-- Indexes for Performance
CREATE INDEX idx_batches_owner_status ON calculation_batches(owner_id, status);
CREATE INDEX idx_periods_batch_user ON user_calculation_periods(batch_id, user_id);
CREATE INDEX idx_results_batch_user ON calculation_results(batch_id, user_id);
CREATE INDEX idx_details_result_step ON calculation_details(result_id, production_step_id);
CREATE INDEX idx_notifications_user_status ON calculation_notifications(user_id, status);
CREATE INDEX idx_audit_timestamp ON calculation_audit_log(timestamp);
```

```tsx
export function BatchWizard() {

              isCompleted={step > index + 1}
            />
          ))}
        </div>
      </div>

      {/* Step Content */}
      <Card>
        <CardHeader>
          <CardTitle>{steps[step - 1].title}</CardTitle>
          <CardDescription>{steps[step - 1].description}</CardDescription>
        </CardHeader>
        
        <CardContent>
          {step === 1 && <BasicInfoStep />}
          {step === 2 && <PeriodConfigStep />}
          {step === 3 && <UserSelectionStep />}
          {step === 4 && <ReviewStep />}
        </CardContent>
        
        <CardFooter className="flex justify-between">
          <Button
            variant="outline"
            onClick={() => setStep(step - 1)}
            disabled={step === 1}
          >
            Previous
          </Button>
          <Button
            onClick={() => step === 4 ? handleSubmit() : setStep(step + 1)}
          >
            {step === 4 ? 'Create Batch' : 'Next'}
          </Button>
        </CardFooter>
      </Card>
    </div>
  );
```

```typescript
export class DataEncryption {
  private static readonly ENCRYPTION_KEY = process.env.ENCRYPTION_KEY!;
  
  static encrypt(data: string): string {
    const cipher = crypto.createCipher('aes-256-cbc', this.ENCRYPTION_KEY);
    let encrypted = cipher.update(data, 'utf8', 'hex');
    encrypted += cipher.final('hex');
    return encrypted;
  }
  
  static decrypt(encryptedData: string): string {
    const decipher = crypto.createDecipher('aes-256-cbc', this.ENCRYPTION_KEY);
    let decrypted = decipher.update(encryptedData, 'hex', 'utf8');
    decrypted += decipher.final('utf8');
    return decrypted;
  }
}
```

```typescript
export class OptimizedCalculationEngine {
  async calculateEmployeeSalaryOptimized(
    userId: string, 
    startDate: Date, 
    endDate: Date,
    ownerId: string
  ): Promise<EmployeeSalaryResult> {
    // Single optimized query instead of multiple round trips
    const results = await db
      .select({
        actualQuantity: employeeSalaryEntrySchema.actualQuantity,
        factoryPrice: productionStepDetailSchema.factoryPrice,
        stepId: productionStepDetailSchema.id,
        stepName: productionStepSchema.stepName,
        entryId: employeeSalaryEntrySchema.id,
      })
      .from(employeeSalaryEntrySchema)

      )
      .innerJoin(
        productionStepSchema,
        eq(productionStepDetailSchema.productionStepId, productionStepSchema.id)
      )
      .where(
        and(
          eq(employeeSalaryEntrySchema.userId, userId),
          eq(employeeSalaryEntrySchema.ownerId, ownerId),
          gte(employeeSalaryEntrySchema.createdAt, startDate),
          lte(employeeSalaryEntrySchema.createdAt, endDate),
          gt(productionStepDetailSchema.factoryPrice, 0) // Only entries with pricing
        )
      );

    // Process results efficiently
    const details = results.map(row => ({
      productionStepId: row.stepId,
      stepName: row.stepName,
      quantity: row.actualQuantity,
      unitPrice: row.factoryPrice,
      amount: row.actualQuantity * row.factoryPrice,
      sourceEntryId: row.entryId,
    }));

    const total = details.reduce((sum, detail) => sum + detail.amount, 0);

    return { total, details };
  }

  // Batch processing with parallel execution
  async calculateBatchParallel(batchId: string): Promise<BatchResult> {
    const userPeriods = await this.getUserPeriods(batchId);
    
    // Process users in chunks to avoid overwhelming the database
    const chunkSize = 10;
    const chunks = chunk(userPeriods, chunkSize);
    const allResults = [];

    for (const userChunk of chunks) {
      // Process chunk in parallel
      const chunkPromises = userChunk.map(async (period) => {
        try {
          return await this.calculateUserSalary(period);
        } catch (error) {
          console.error(`Error calculating salary for user ${period.userId}:`, error);
          throw error;
        }
      });

      const chunkResults = await Promise.allSettled(chunkPromises);
      allResults.push(...chunkResults);

      // Add small delay between chunks to prevent database overload
      await new Promise(resolve => setTimeout(resolve, 100));
    }

    return this.processResults(allResults);
  }
```

### Caching Strategy
```typescript
// Multi-layer caching for performance
import { Redis } from 'ioredis';

export class CalculationCache {
  private redis: Redis;
  private memoryCache: Map<string, any> = new Map();

  constructor() {
    this.redis = new Redis(process.env.REDIS_URL!);
  }

  // L1: Memory cache for frequently accessed data
  async getFromMemory<T>(key: string): Promise<T | null> {
    const cached = this.memoryCache.get(key);
    if (cached && cached.expiry > Date.now()) {
      return cached.data;
    }
    return null;
  }

  async setInMemory<T>(key: string, data: T, ttlSeconds: number = 300): Promise<void> {
    this.memoryCache.set(key, {
      data,
      expiry: Date.now() + (ttlSeconds * 1000)
    });
  }

  // L2: Redis cache for calculation results
  async getCalculationResult(userId: string, periodHash: string): Promise<CalculationResult | null> {
    const key = `calc:${userId}:${periodHash}`;
    
    // Try memory cache first
    const memoryResult = await this.getFromMemory<CalculationResult>(key);
    if (memoryResult) return memoryResult;

    // Try Redis cache
    const redisResult = await this.redis.get(key);
    if (redisResult) {
      const parsed = JSON.parse(redisResult);
      await this.setInMemory(key, parsed, 300); // Cache in memory for 5 minutes
      return parsed;
    }

    return null;
  }

  async setCa lculationResult(
    userId: string, 
    periodHash: string, 
    result: CalculationResult
  ): Promise<void> {
    const key = `calc:${userId}:${periodHash}`;
    
    // Cache in both layers
    await this.setInMemory(key, result, 300);
    await this.redis.setex(key, 3600, JSON.stringify(result)); // 1 hour in Redis
  }

  // Cache invalidation
  async invalidateUserCalculations(userId: string): Promise<void> {
    const pattern = `calc:${userId}:*`;
    
    // Clear from memory cache
    for (const key of this.memoryCache.keys()) {
      if (key.startsWith(`calc:${userId}:`)) {
        this.memoryCache.delete(key);
      }
    }

    // Clear from Redis
    const keys = await this.redis.keys(pattern);
    if (keys.length > 0) {
      await this.redis.del(...keys);
    }
  }
}
```

```typescript
  // Performance metrics for optimization
  static async getPerformanceMetrics(ownerId: string) {
    const metrics = await db
      .select({
        totalBatches: sql<number>`COUNT(*)`,
        activeBatches: sql<number>`COUNT(*) FILTER (WHERE status IN ('draft', 'calculating'))`,
        avgCalculationTime: sql<number>`AVG(EXTRACT(EPOCH FROM (${calculationBatches.calculatedAt} - ${calculationBatches.createdAt})))`,
        avgUsersPerBatch: sql<number>`AVG(${calculationBatches.totalUsers})`,
        successRate: sql<number>`COUNT(*) FILTER (WHERE status = 'finalized') * 100.0 / COUNT(*)`,
        incrementalUsageRate: sql<number>`COUNT(*) FILTER (WHERE ${calculationBatches.incrementalMode} = true) * 100.0 / COUNT(*)`,
      })
      .from(calculationBatches)
      .where(eq(calculationBatches.ownerId, ownerId));

    const result = metrics[0];
    
    return {
      totalBatches: result.totalBatches,
      activeBatches: result.activeBatches,
      avgCalculationTimeSeconds: parseFloat(result.avgCalculationTime?.toString() || '0'),
      avgUsersPerBatch: parseFloat(result.avgUsersPerBatch?.toString() || '0'),
      successRate: parseFloat(result.successRate?.toString() || '0'),
      incrementalUsageRate: parseFloat(result.incrementalUsageRate?.toString() || '0'),
```

```typescript
      database: await this.checkDatabaseHealth(),
      redis: await this.checkRedisHealth(),
      calculationEngine: await this.checkCalculationEngineHealth(),
      notifications: await this.checkNotificationHealth(),
      overallStatus: 'healthy' as 'healthy' | 'degraded' | 'unhealthy'
    };

    // Determine overall status
    const services = [health.database, health.redis, health.calculationEngine, health.notifications];
    const unhealthyServices = services.filter(service => service.status === 'unhealthy').length;
    const degradedServices = services.filter(service => service.status === 'degraded').length;

    if (unhealthyServices > 0) {
      health.overallStatus = 'unhealthy';
    } else if (degradedServices > 0) {
      health.overallStatus = 'degraded';
    }

    return health;
  }

  private static async checkDatabaseHealth() {
    try {
      const start = Date.now();
      await db.select().from(calculationBatches).limit(1);

        status: responseTime < 100 ? 'healthy' : (responseTime < 500 ? 'degraded' : 'unhealthy'),
        responseTime,
        lastCheck: new Date()
      };

        status: 'unhealthy',
        error: error.message,
        lastCheck: new Date()
      };
    }
  }

        status: responseTime < 1000 ? 'healthy' : (responseTime < 3000 ? 'degraded' : 'unhealthy'),
        responseTime,
        lastCheck: new Date(),
        testResult: testResult.isValid
      };
    } catch (error) {
      return {
        status: 'unhealthy',
        error: error.message,
        lastCheck: new Date()
      };
    }
  }
```
