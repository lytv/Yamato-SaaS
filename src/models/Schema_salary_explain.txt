## 💼 Yêu cầu Nghiệp vụ

### Dữ liệu đầu vào:
1. **Production Step Detail**: Chứa đơn giá cho từng công đoạn
   - `Factory Price`: Đơn giá áp dụng cho Employee Salary Entry
   - `Calculated Price`: Đơn giá áp dụng cho Outsource Order Receipt

2. **Employee Salary Entry**: Dữ liệu lương nhân viên
   - `Actual Quantity`: Số lượng thực tế hoàn thành

3. **Outsource Order Receipt**: Dữ liệu nhận hàng outsource
   - `Received`: Số lượng đã nhận

### Công thức tính toán:
```
Employee Salary = Σ(Factory Price × Actual Quantity)
Outsource Amount = Σ(Calculated Price × Received)
Total Salary = Employee Salary + Outsource Amount
```

### Yêu cầu thời gian:
- **Thời gian chung**: Áp dụng cho tất cả users
- **Thời gian riêng**: Override cho từng user cụ thể
- **Tracking**: Lưu lại kết quả để review sau này

## 🏗️ Phương án được chọn: Calculation Batch Approach

### Kiến trúc tổng quan:
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│ Calculation     │    │ User Calculation │    │ Calculation     │
│ Batches         │───▶│ Periods          │───▶│ Results         │
│ (Master)        │    │ (User-specific)  │    │ (Final Output)  │
└─────────────────┘    └──────────────────┘    └─────────────────┘
         │                        │                        │
         ▼                        ▼                        ▼
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│ Batch Templates │    │ Calculation      │    │ Calculation     │
│ (Standardize)   │    │ Audit Log        │    │ Details         │
└─────────────────┘    │ (Tracking)       │    │ (Breakdown)     │
                       └──────────────────┘    └─────────────────┘
```

### Core Components:

#### 1. **Calculation Batches** (Bảng chủ)
- Quản lý các đợt tính toán lương chính thức
- Chứa thời gian default áp dụng cho tất cả users
- Status workflow: `draft` → `calculating` → `calculated` → `finalized`
- Metadata: tổng số users, tổng số tiền, notes

#### 2. **User Calculation Periods** (Thời gian User)
- Override thời gian default cho user cụ thể
- Lưu lý do thay đổi (nghỉ phép, gia nhập muộn, etc.)
- Status riêng cho từng user: `pending` → `calculating` → `calculated`
- Exclude users khỏi calculation nếu cần

#### 3. **Calculation Results** (Kết quả)
- Lưu kết quả tính toán cuối cùng cho từng user
- Breakdown: Employee Salary + Outsource Amount = Grand Total
- Validation tracking và error handling
- Performance metrics (calculation time)

#### 4. **Calculation Details** (Chi tiết)
- Breakdown theo từng production step
- Link đến source data để traceability
- Cached pricing information
- Detailed calculation: quantity × unit price = amount

#### 5. **Calculation Audit Log** (Audit Trail)
- Log mọi thao tác quan trọng
- Change tracking (before/after values)
- User action tracking
- Compliance và debugging support

## 🔄 Workflow và Use Cases

### 1. **Standard Monthly Payroll Workflow**
```
1. HR tạo Calculation Batch "Lương tháng 12/2024"
   ├─ Set default period: 01/12/2024 - 31/12/2024
   ├─ Auto-populate tất cả active users
   └─ Status: draft

2. HR review và adjust periods cho special cases
   ├─ User A: nghỉ phép → custom period: 05/12/2024 - 31/12/2024  
   ├─ User B: gia nhập muộn → custom period: 15/12/2024 - 31/12/2024
   └─ User C: exclude (nghỉ không lương)

3. Trigger calculation
   ├─ Status: draft → calculating
   ├─ 🆕 Real-time progress tracking (0-100%)
   ├─ 🆕 Automatic notifications sent to stakeholders
   ├─ Process từng user (parallel/sequential)
   ├─ 🆕 Incremental calculation if enabled
   ├─ Generate calculation_results và calculation_details
   └─ Status: calculating → calculated

4. HR review results
   ├─ Check validation errors
   ├─ 🆕 Review performance metrics và optimization suggestions
   ├─ 🆕 Verify data integrity với source data versioning
   ├─ Verify totals và breakdowns
   └─ Request re-calculation nếu cần

5. Finalize batch
   ├─ Status: calculated → finalized
   ├─ 🆕 Final notifications sent to all users
   ├─ Lock data (no more changes)
   └─ Export payroll reports
```

### 2. **Ad-hoc Calculation Workflow**
```
1. Manager cần quick calculation cho bonus
   ├─ Tạo batch "Bonus Q4 2024"
   ├─ Set period: 01/10/2024 - 31/12/2024
   └─ Select specific users only

2. Override periods cho performance-based calculation
   ├─ Top performer: full quarter
   ├─ New joiners: prorated period
   └─ Underperformers: excluded

3. Calculate và review quickly
4. Use for decision making (không finalize)
```
